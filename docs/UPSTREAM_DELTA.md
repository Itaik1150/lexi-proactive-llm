## Keeping in sync with upstream

This repository and upstream share **no common Git ancestor** (Lexi was copied in as a folder in commit `132e415`), so `git merge upstream/main` cannot work directly.
To pull an upstream fix: `git fetch upstream`, then `git diff upstream/main:<path> HEAD:Lexi/<path>` for the file you care about and port the change by hand.
Keeping thesis edits small and in the files listed above makes this manageable; avoid reformatting or moving upstream files.
